# Core Gameplay

First serious playable loop:
wake up -> shower -> dress -> eat -> use phone -> buy mobile data -> travel/drive -> work -> earn money -> shop -> exercise -> interact with persistent NPCs -> pay bills -> return home -> sit/lie down -> sleep -> save/reload correctly.

## Interaction set
Sit, stand, lie down, move while lying down, sleep, cook, eat, drink, shower, use toilet, wash clothes, iron, watch TV, use phone, use laptop, open/lock doors, open windows, use appliances, clean, carry objects, move furniture, drive, enter/exit vehicles, shop, talk, work, study and exercise.
