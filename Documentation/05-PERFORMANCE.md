# Performance and Graphics

- Unity 6 + URP.
- Realistic presentation with scalable runtime quality.
- Selective high-resolution source assets, including up-to-8K where useful; never force 8K runtime textures everywhere.
- LOD/HLOD, occlusion, texture streaming, pooled NPCs/traffic, dynamic resolution and device-specific quality settings.
- Mobile priorities: memory, thermals, battery, frame pacing and storage.
- Windows PC: higher density, draw distance, reflections, texture tiers and optional high-resolution output where hardware supports it.
