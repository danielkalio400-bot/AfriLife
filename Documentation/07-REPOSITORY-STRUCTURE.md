# Repository Structure

- GameClient/ — Unity client and starter code
- Backend/ — account/world-service scaffolding
- GameServers/ — future multiplayer/session hosting
- Database/ — migrations and persistence schemas
- Shared/ — versioned contracts and catalogs
- Infrastructure/ — deployment/observability plans
- ArtSource/ — editable original/licensed source assets
- Tools/ — project and content pipeline utilities
- Tests/ — cross-system and performance test plans
- Documentation/ — architecture and production documentation
- .github/ — CI automation

No backup copies or generated build folders belong in the repository.
