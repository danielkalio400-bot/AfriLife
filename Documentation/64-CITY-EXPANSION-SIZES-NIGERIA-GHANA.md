# AfriLife — Nigeria + Ghana planned city land sizes

This is a **future playable-area allocation**, NOT real city area, delivered terrain, multiplayer instances, world boundaries, or downloadable game assets.

The first ten areas retain the previously agreed 100% increase. For remaining cities, the transparent planning default is **64 km²** for a Nigerian state's first selected city, **25 km²** for additional Nigerian cities, **49 km²** for a Ghanaian region's first selected city, and **16 km²** for additional Ghanaian cities. These are editable proposals, not sourced geographic measurements.

Coverage: 84 named city footprints (58 Nigeria; 26 Ghana) across all 53 administrative units. Total allocation **4,625 km²**, about **1,142,862 acres**. Only Lagos and Accra have actual Unity city scenes, at much smaller currently authored scale.
